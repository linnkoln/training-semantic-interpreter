# Эталонные JSON для TC-001 и TC-002

Папки `TC-001/` и `TC-002/` содержат полные ожидаемые файлы после Save: `rulesLog.json`, `graph.json` и `data.json`. Их полный текст также вставлен в узлы соответствующих Canvas-спецификаций.

- `rulesLog.json` сохраняет все созданные версии правила по порядку. Первая версия появляется после обработки 05-29; вторая добавляет примеры 05-31; третья появляется после 07-21. Пустых версий нет. У каждой записи один номер версии, реальные примеры и соответствия ключей. Старые версии не теряются. Ушедшие `push_knees_reps` и `pull_rings_reps` отсутствуют только в актуальной версии 3.
- `graph.json` сохраняет отношения, созданные в предыдущих тестах. После TC-002 в нём две пары A+B из TC-001 и два новых отношения overlay. Поля `targets` и `trends` не сохраняются.
- `data.json` хранит неизменные события с полями `date` и `values`; самые поздние даты идут первыми. Старые события сохраняют прежние значения.

Временные метки в эталонном логе фиксируют пример состояния; при живом запуске их конкретные значения зависят от времени Save. Семантическое сравнение проверяет порядок версий, значения, примеры и отношения.
