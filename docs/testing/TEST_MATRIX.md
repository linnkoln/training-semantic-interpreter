## Сводка закрытия

- Автоматический suite покрывает модули и часть UI-логики на mocks; он не моделирует реальный Obsidian Vault целиком и не является свидетельством Gemma качества.
- TC-001 и TC-002: три свежих core-pipeline Gemma repeats для каждого anchor завершились по своим oracle; подробности и evidence — в anchor run reports. Ранние single runs остаются историческими.
- Прежние якорные `core-pipeline PASS 3/3` остаются историческими для значений и отдельных вызовов; новый полный файловый эталон ещё не подтверждён. UI → Vault → reload → chart для обоих в текущем Obsidian — `NOT RUN`.
- Перед live-проверкой сохранить текущие JSON snapshots; после кейсов при необходимости использовать штатную кнопку полного сброса.
