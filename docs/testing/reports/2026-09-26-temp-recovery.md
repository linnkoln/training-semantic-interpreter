# Восстановление временных файлов — 2026-09-26

Источник: пользовательская `docs/user/artifacts/architecture.canvas`, узел
`8ce01f0c60632959` «Программа запущена», и текущая задача о ререндерах Obsidian.

Рендер больше не очищает `data.tmp.json`, `rulesLog.tmp.json`, `graph.tmp.json`.
Восстанавливаются события, полные предложения правил, минорные примеры, роли
метрик и отношения графа. JSON показывается от поздней даты к ранней; сохранённые
события имеют приоритет над temp с той же датой. Непустой temp включает сообщение
на графике и кнопку «Очистить временные файлы»; пустые файлы и UI state — нет.

из памяти, чтобы последующий Save не вернул их. Общий Save работает после reload.

пересобранными bundle в одном окне. Новый экземпляр блокирует конкурирующие
действия и после завершения перечитывает результат из Vault. Данные не становятся
истиной из общего runtime-состояния: источник восстановления — файлы.
