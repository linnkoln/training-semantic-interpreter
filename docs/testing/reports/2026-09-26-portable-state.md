# Проверка переносимости пользовательского состояния

Дата: 2026-09-26. Это инженерный отчёт о подготовке коммита, не новая пользовательская спецификация.

Общая логика добавления данных остаётся общей для всех установок. Рабочие события, правила, вокабулярий, граф, UI-state, временные файлы и резервные копии принадлежат конкретному пользователю. Тестовые fixtures, reference JSON и описания пользовательской логики остаются в репозитории.

## Изменения

- `.gitignore` исключает рабочее состояние, личные архивные JSON, prompt-lab и `work/`.
- 15 ранее отслеживаемых файлов личного состояния сняты только с учёта Git. Файлы на диске сохранены; непосредственно до и после снятия с учёта их SHA-256 совпали.
- `data/defaults/rulesLog.json` и `data/defaults/graph.json` — пустые стартовые шаблоны. `tools/build.js` использует их для виртуальных ресурсов и fs-shim; рабочее состояние автора больше не встраивается в `bundle.js`.
- Отсутствующий личный журнал означает пустое состояние в памяти. Чтение не создаёт файл; первый явный Save сохраняет собственные события, правила и граф. Ошибка JSON или другая ошибка чтения в Node не подменяется отсутствующим журналом.
- Сборщик нормализует CRLF/LF при чтении исходников и ресурсов, чтобы одинаковый исходный текст давал одинаковое содержимое сборки и buildId на разных checkout.
- Тесты, зависевшие от живого журнала или графа, переведены на изолированные начальные состояния. Проверка сохранения явных связей использует явный тестовый граф.
- Pre-commit сохраняет guard; при отсутствии `npm` запускает ту же команду тестов через `node`.

## Границы результата

Проверка выполнена на core и browser bundle с mock Vault; живой Obsidian и качество модели здесь не проверялись. Открытые наблюдения Router/RuleUpdate и приёмки перечислены в [отчёте Repair Map 10/12](2026-09-26-branch2-save-temp.md).

Личные файлы исключены из текущего дерева Git. В старых коммитах они могут оставаться: `.gitignore` и снятие с учёта не очищают историю. Выбор способа подготовки публичной истории входит в последующий аудит; переписывание истории и публикация сейчас не выполнялись.

`git diff --cached --check` сохраняет две строки с пробелами в пользовательских цитатах `docs/user/chart-rendering-rules.md:32–33`. Текст пользователя не переписывался ради форматирования. Машинные EOF-предупреждения устранены.
