# docs/user/ — ПОЛЬЗОВАТЕЛЬСКАЯ ДОКУМЕНТАЦИЯ (уровень 1, высший приоритет)

> Сюда входят ТОЛЬКО: (1) артефакты, написанные пользователем, (2) дословные цитаты пользователя
> на протяжении проекта + контекст, в котором они были сказаны. Контекст пишет агент; слова
> пользователя — НЕ меняются, НЕ paraphrase'ятся, НЕ сокращаются.

## Правила (зафиксированы пользователем 2026-08-30)

1. Машинная документация (доки, написанные агентами) ССЫЛАЕТСЯ сюда. При конфликте
   инструкций здешние перекрывают машинные.
2. При конфликте машинной документации с этой — агент НЕ правит её сам, а обращается к
   пользователю с просьбой переписать/разрешить конфликт. Пользователь разрешает его САМ.
3. Агент может дополнять эту папку новыми цитатами (с контекстом) — но не более: не редактировать
   слова пользователя, не «улучшать» формулировки, не удалять цитаты. Цитата записывается ТОЛЬКО
   когда пользователь сам скажет, что её стоит запомнить.
4. Инструкции не «истина»: любая может столкнуться с реальностью и потребовать пересмотра.
   До столкновения не предполагаем её непогрешимость — просто здесь высший приоритет.
5. Ничто в `docs/` вне этой папки не может задавать «что имел в виду пользователь».
   Формулировки вида «по уточнению заказчика» вне этой папки — это ПЕРЕСКАЗ агента, пока здесь
   нет подтверждающей цитаты.

## Файлы

- `quotes.md` — дословные цитаты пользователя (дата, контекст, источник-сессия).
- `artifacts/` — артефакты, написанные пользователем целиком.
- `chart-rendering-rules.md` — правила отрисовки графиков (тренды — на основании
  дословных цитат 2026-08-31; подписи цифр/оформление — формулировки агента по
  истории 2026-08-28, помечены как требующие подтверждения пользователя).
- `DECISIONS.md`, `decisions - assessment.md` — пользовательская постановка D11 и
  реестр вердиктов пользователя на машинные решения.
